# Translator Skill

## Description
Detects and translates text between 100+ languages. Supports auto-detection of source language, translation to a target language, and listing all supported languages.

## Triggers
- translate text
- detect language
- what language is this
- translate to spanish

## Usage
Use detect(text) to identify language, translate(text, target_lang, source_lang=None) to translate, and get_supported_languages() to list all available languages.
