# Notes Skill

This skill allows JARVIS to maintain a persistent record of your ideas, task lists, and research summaries.

## Instructions
1. Use `append` to add a new note to the end of the `jarvis_notes.txt` file.
2. Use `read` to review past notes.
3. Use `clear` (with confirmation) to wipe the current notes file.
4. When summarizing research, always offer to save the findings as a note.

## Files
- `jarvis_notes.txt`: The primary storage for this skill.
