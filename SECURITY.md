# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 3.0     | ✅ Active |
| 2.1     | ⏳ Limited (critical fixes only) |
| 2.0     | ❌ End of life |
| < 2.0   | ❌ End of life |

## Reporting a Vulnerability

Please **do not** file a public GitHub issue. Report privately to **security@gogeta.ai**.

Include a description, steps to reproduce, affected version(s), and potential impact. We acknowledge receipt within 48 hours.

## Full Policy

See [.github/SECURITY.md](.github/SECURITY.md) for the complete security policy, including the trust model, scope definitions, and disclosure process.
